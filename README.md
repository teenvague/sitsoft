# Sit Soft — Brand Strategy Session

## Edit the questions
Open `data.js`.

All section names and question copy are grouped there in one simple array. You do not need to touch the HTML or interaction code.

## Interaction
- Tap right side: next
- Tap left side: previous
- Arrow keys work on desktop
- Short vibration haptic where supported
- Full-bleed slide background on mobile and desktop
- Automatic black/white text based on background contrast
- Dynamic progress-dot sizing per section

## Visual system
- One typography style throughout section cards and question cards
- Matching tracked-out type treatment
- No desktop black frame around the mobile canvas
- No outlines/borders on cards or tap zones
